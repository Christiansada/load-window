## LinkedIn

I built Load Window, an open-source energy scheduling lab for educators and analysts exploring flexible loads.

Give it 24 hourly prices, a base load, a power cap, and up to three continuous tasks. It checks every allowed start combination, compares the lowest-cost feasible schedule with your baseline, and exports an inspectable JSON review.

The interface includes hourly demand comparisons, exact values, explicit infeasibility, and results that clear when assumptions change. It runs in the browser without an account or data upload.

The bundled example is synthetic. This is an hourly constant-power model, not measured savings, a bill forecast, or equipment control.

App: https://christiansada.github.io/load-window/
Code: https://github.com/Christiansada/load-window

Contributions welcome: review import, variable base demand, and assistive-technology testing.
